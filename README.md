# The Agentic Enterprise — Open Curriculum

Free, adaptable teaching and reference materials built on the book
**_What the Structure Does Not Carry_** by Georg Zangl (2026), foreword by
Egbert U. Imomoh.

Every offering shares one spine — the custody law, the six properties (context,
authority, accountability, coordination, execution coherence, institutional
memory), the four axioms, the nine-test evaluation protocol, and the six custody
rules. Only depth, pace, and audience change.

> **Students never need to buy the book.** Every course is built so that all
> teaching, assignments, and exams can be completed from the materials here. The
> book is recommended enrichment (Kindle ~US$2.99), never a prerequisite for any
> graded work. Instructors will get more from having a copy.

All files are editable Word (`.docx`) and PowerPoint (`.pptx`) so you can rebrand
and adapt them; export your own PDFs for students.

## The idea in one paragraph

An enterprise is not its systems — those get replaced — but a small set of
**properties** that must survive every boundary a piece of work crosses. For
decades a hidden layer of people carried those properties by hand across the
gaps in every architecture diagram. Agentic AI does not create a new
requirement; it **withdraws that subsidy.** The materials teach you to see the
crossings, name the property at risk at each one, and judge any architecture by a
single demand: *show the crossing, and show what survives it.*

## How to use these materials

1. Open a course folder and read its syllabus first; each folder has its own
   README describing the files.
2. Search each file for placeholders in square brackets — `[Instructor name]`,
   `[Term / year]`, `[Institution]`, suggested course codes — and complete them
   for your programme.
3. Export PDFs for students however you prefer, with your own branding.
4. Adapt freely within the licence: swap in local incidents, re-weight the
   assessment, split a deck by week. Keep the spine; change everything around it.
